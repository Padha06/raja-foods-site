# Raja Foods website

Public website for Raja Foods and its four businesses: the broiler farm, district wholesale, local live-bird distribution (Raja Wholesale) and Raja Broilers retail & hotel supply. English and Hindi.

Live: https://raja-foods-site.vercel.app

## Run locally

```bash
npm install
npm run dev
```

## Where to change things

- `src/config.js`: phone / WhatsApp number, address, hours, today's rates, districts, photos, staff login link
- `src/content.js`: all page copy in English and Hindi, business descriptions, FAQ

Pushing to `main` deploys to Vercel automatically.

Built with Vite, React, Tailwind CSS v4, Motion and Lenis.
